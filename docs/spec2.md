# 番茄鐘功能規格

建立日期：2026-11-25

## 功能範圍

- 首頁新增「番茄鐘」入口，開啟獨立的番茄鐘頁面。
- 第一版只支援電腦，介面文字使用繁體中文，沿用網站既有風格。
- 番茄鐘不包含任務清單或每日歷史紀錄；畫面只呈現目前四番茄循環的進度。
- 設定、目前計時階段、剩餘時間、循環進度及專注事項保存在目前瀏覽器。

## 專注事項與時間設定

- 使用者可輸入或清除本次要專注的事項；欄位可留白。專注事項保存在目前瀏覽器，直到使用者更改或清除。
- 專注事項可在開始下一段專注前更改或清除。專注倒數進行或暫停時，該時段保留原有事項。
- 預設時間如下：

  | 階段 | 預設時間 |
  | --- | ---: |
  | 專注 | 25 分鐘 |
  | 短休息 | 5 分鐘 |
  | 長休息 | 20 分鐘 |

- 三種時間都可調整為任意正整數分鐘。
- 計時階段開始後，修改設定不會改變當前倒數；新設定從下一階段計時開始生效。

## 計時流程

- 使用者明確開始每一段專注計時。專注倒數可暫停及繼續；暫停期間不計時。
- 專注倒數未完成時，使用者可重設該專注時段。重設會清除該時段已經過的時間，不增加番茄數。
- 專注時間完整結束時，立即記下一個番茄並自動開始休息倒數。
- 每完成前三個番茄後自動開始短休息；完成第四個番茄後自動開始長休息。
- 休息倒數開始後會持續計時至結束，不提供頁面內的暫停、略過或延長操作。
- 休息倒數結束時提示使用者，等待使用者明確開始下一段專注。
- 長休息結束時，將循環進度歸零，開始新的四番茄循環。

## 循環重設

- 使用者可重設目前循環；執行前須確認。
- 重設會將已完成番茄數歸零，並取消未完成的專注計時；專注事項保留。
- 休息倒數進行中不提供循環重設操作。

## 保存與提示

- 番茄鐘資料只保存在目前瀏覽器；不包含帳號或跨裝置同步功能。
- 番茄鐘頁面仍開啟時，即使位於背景分頁，計時也會繼續。
- 關閉或重新整理頁面時，暫停目前階段並保存剩餘時間；重新開啟後從保存的狀態繼續。
- 計時結束時顯示頁面提示並播放短音效；使用者可靜音。
- 可選擇啟用瀏覽器桌面通知；只有使用者啟用時才詢問通知權限。
